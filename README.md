# Portfolio Showcase

A modern, interactive portfolio website showcasing web development projects with a clean and professional design.

## Features

- Dynamic project grid with modal previews
- Responsive design for all devices
- Smooth animations and transitions
- Visit counter tracking
- Back to top navigation
- Image viewer for project screenshots
- Professional hero section with call-to-action

## Tech Stack

- HTML5
- CSS3 (Custom animations and grid layouts)
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts (Inter)

## Usage

Open `index.html` in a web browser to view the portfolio showcase. The website features:

- Hero section with developer introduction
- Featured projects grid
- Interactive project modals with detailed information
- Responsive footer with social links

## Development

The project structure:
- `index.html` - Main HTML file
- `styles.css` - Main stylesheet
- `script.js` - Core JavaScript functionality
- `css/imageViewer.css` - Image viewer styles
- `js/imageViewer.js` - Image viewer functionality
